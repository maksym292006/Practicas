README: Panadería Somontano - Landing PageComponente React para la interfaz principal de la Panadería Somontano en Barbastro. Implementa una arquitectura de diseño basada en componentes modulares para la exhibición de productos artesanales y gestión de información local.Estructura del DocumentoEl archivo define el componente funcional PanaderiaSomontano, organizado en las siguientes secciones lógicas:Hero & Propuesta de Valor: Introducción visual y declaración de misión (procesos lentos, materia prima local).Catálogo de Especialidades: Grid interactivo utilizando ServiceCard para mostrar productos destacados (Hogaza, Trenza de Almudévar, Empanada).**Conversión (Reservas)****: Bloque de acción para pedidos online y reservas de mesa.Información Operativa: Doble columna con horarios de apertura y cronograma preciso de salida del horno.Transparencia Alimentaria: Tabla técnica de ingredientes y alérgenos para cumplimiento normativo y seguridad del consumidor.Ubicación y Gestión: Datos de contacto, mapa referencial y acceso rápido a funciones de administración de stock.Requisitos y DependenciasEl componente depende de una biblioteca de componentes interna (design-system):ComponenteOrigenFunciónNavbar@/components/design-system/navbarNavegación global.Hero@/components/design-system/HeroCabecera de alto impacto.ServiceCard@/components/design-system/serviceCardVisualización de producto y precio.Button@/components/design-system/ButtonElementos de interacción (variantes: primary, outline, secondary).Footer@/components/design-system/FooterCierre de página y créditos.Especificaciones TécnicasEstilizado: Utiliza Tailwind CSS.Paleta de Colores:Primario: #A76F22 (Ocre/Dorado para acentos y títulos).Fondo destacado: #ECD1B4 (Crema/Trigo para secciones de acción).Base: gray-900 para legibilidad de texto y white para limpieza visual.Accesibilidad:Uso de aria-label en tarjetas de servicio.Roles de imagen definidos (role="img") en secciones no textuales.Estados de foco optimizados mediante focus-visible.Layout: Diseño responsivo basado en grid y flexbox con soporte para dispositivos móviles (grid-cols-1) y escritorio (md:grid-cols-3).Gestión de DatosLa información de productos y horarios está actualmente integrada de forma estática en el JSX. Para escalabilidad, se recomienda la extracción de estos objetos a un archivo de configuración constants.js o la implementación de un fetch desde un CMS.EntidadPropiedades ClaveProductoTítulo, descripción, precio, variante de diseño.HorarioDía, franja horaria.HorneadoTipo de pan, hora de salida.
